# B2A Smart Farming

Application d'élevage gratuite, utilisable sans internet.

**Ouvrir l'application :** https://azizyou2005.github.io/b2a-smart-farming/

Sur le téléphone : ouvrir le lien une fois avec internet, puis menu du navigateur > « Ajouter à l'écran d'accueil ». Ensuite elle marche sans internet.
